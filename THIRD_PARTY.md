The original [SeenKid/shavit-line](https://github.com/SeenKid/shavit-line/tree/2936a9204a432d4a492c89ae9af4a5dc51ca242d), specifically `botpath.sp` lines 81 and 111–188, was consulted for the 0.5-unit straight beam links, 20-unit four-edge boxes, +2.5 Z offset, airborne-to-ground contact detection and nearest-position 2500-frame window. RouteLine reimplements that geometry in C++ using CS2 native beam entities, with the user's white/blue/red palette. Version 0.6 replaces direct contact-to-contact links with an independently implemented, error-bounded simplification of the recorded trajectory, preserving movement-state anchors and crouch boundaries. Version 0.7 adds independently implemented least-squares cubic Bezier fitting, source-corridor validation, adaptive straight-beam subdivision and coalescing, with separate curve/color boundaries. No third-party curve-fitting code is copied. Unlike the original Source 1 temporary-beam messages, these CS2 entities are retained and shared across overlapping per-player windows. Source 1 materials and network API are not used, so exact material/appearance equivalence is not claimed. Its SourcePawn implementation is not copied here. This is a new CS2 plugin, not an official port or release from that project.

Version 0.8 estimates contact within a tick using positions and velocities. The 64 Hz tick and Classic's forced half tick split, gravity and jump impulse follow the pinned CS2KZ [Classic movement code](https://github.com/KZGlobalTeam/cs2kz-metamod/blob/6f7ad5eb778cc80cfc1f31c330084616ffb753bc/src/kz/mode/kz_mode_ckz.cpp#L256) and [mode settings](https://github.com/KZGlobalTeam/cs2kz-metamod/blob/6f7ad5eb778cc80cfc1f31c330084616ffb753bc/src/kz/mode/kz_mode_ckz.h#L117). The estimator is implemented in RouteLine.

Version 0.9 uses the CS2 `path_particle_rope` entity and documents the Valve path keys using shipped map entity lumps. The add-on contains two RouteLine particle definitions authored for this renderer. They reference the stock white texture and path snapshot supplied by CS2. See the [Valve rope entity definition](https://github.com/SteamTracking/GameTracking-CS2/blob/master/game/core/base.fgd#L6673) and the pinned CS2KZ [resource hook](https://github.com/KZGlobalTeam/cs2kz-metamod/blob/6f7ad5eb778cc80cfc1f31c330084616ffb753bc/src/utils/hooks.cpp#L679) and [physics query wrapper](https://github.com/KZGlobalTeam/cs2kz-metamod/blob/6f7ad5eb778cc80cfc1f31c330084616ffb753bc/src/sdk/navphysicsinterface.h#L9).

Version 0.10 uses the [CounterStrikeSharp AcceptInput signature](https://github.com/roflmuffin/CounterStrikeSharp/blob/main/configs/addons/counterstrikesharp/gamedata/gamedata.json#L162) to call the native rope `DestroyImmediately` input before entity removal. The Linux pattern was verified against the game binary.

The source archive includes this project's code, vendored public headers, licenses and the pinned dependency bootstrap script. Public replay samples used for local validation are not included in the distribution.
